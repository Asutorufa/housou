# d1-orm

A lightweight ORM and migration toolkit for Cloudflare D1.

## Features

- Query builders: `Select`, `Insert`, `Update`, `Delete`
- Model abstraction with `Repository<T>`
- `#[derive(Model)]` support (re-exported from `d1-orm-derive`)
- Schema builders: `Table`, `Column`, `Index`
- Additive migration planning via `additive_migration_sql`
- Runtime migrator with inference probes (`Migrator`, `SchemaProbe`)

## Installation

```toml
[dependencies]
d1-orm = "0.1"
```

## Quick Start

```rust
use d1_orm::{Model, Repository};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize, Model)]
#[d1(table_name = "users")]
struct User {
    #[d1(primary_key, auto_increment)]
    id: i64,
    #[d1(not_null, unique_index, select_by)]
    email: String,
    #[d1(not_null)]
    name: String,
}

async fn find_user(db: &d1_orm::D1Database, id: i64) -> d1_orm::Result<Option<User>> {
    Repository::<User>::new(db).find_by_id(id).await
}

// Auto-generated by #[d1(select_by)] on `email`:
// User::get_by_email(db, "alice@example.com").await
// User::list_by_email(db, "alice@example.com").await
// User::update_by_email(db, "alice@example.com", &[("name", d1_orm::JsValue::from_str("Alice"))]).await
// User::delete_by_email(db, "alice@example.com").await
```

## Complete Example

```rust
use d1_orm::{
    d1_migration, d1_migrations, d1_probe, D1Database, Migrator, Model, Order, Repository,
};
use serde::{Deserialize, Serialize};
use worker::{Env, Result as WorkerResult};

#[derive(Debug, Clone, Serialize, Deserialize, Model)]
#[d1(table_name = "users")]
struct User {
    #[d1(primary_key, auto_increment)]
    id: i64,
    #[d1(not_null, unique_index)]
    email: String,
    #[d1(not_null)]
    name: String,
    #[d1(since = 2)]
    avatar_url: Option<String>,
}

async fn migrate(db: &D1Database) -> d1_orm::Result<()> {
    // applied_at: unix timestamp (seconds)
    let migrations = d1_orm::d1_auto_migrations!(User);
    Migrator::new(db).run(&migrations, 1_700_000_000).await
}

async fn demo_crud(db: &D1Database) -> d1_orm::Result<()> {
    let repo = Repository::<User>::new(db);

    let created = User {
        id: 0,
        email: "alice@example.com".to_string(),
        name: "Alice".to_string(),
        avatar_url: None,
    };
    created.insert(db).await?;

    let mut alice = repo
        .find_one(
            repo.select()
                .where_eq("email", "alice@example.com")
                .order_by("id", Order::Desc),
        )
        .await?
        .ok_or_else(|| d1_orm::Error::NotFound)?;

    alice.name = "Alice Updated".to_string();
    alice.update(db).await?;

    let _rows = repo
        .find_all(repo.select().where_not_null("email").limit(20))
        .await?;

    repo.delete_by_id(alice.id).await?;
    Ok(())
}

// Typical Worker entry style usage.
// The D1 binding name below is "DB".
pub async fn handle(env: Env) -> WorkerResult<()> {
    let db = env.d1("DB")?;
    migrate(&db).await.map_err(|e| worker::Error::RustError(e.to_string()))?;
    demo_crud(&db)
        .await
        .map_err(|e| worker::Error::RustError(e.to_string()))?;
    Ok(())
}
```

## Migrations

You can fully auto-generate migration plans from `#[derive(Model)]` structs:

```rust
let migrations = d1_orm::d1_auto_migrations!(User, Session, UserItem);
```

`d1_auto_migrations!` will:

- infer max schema version from models
- generate setup SQL for first appearance of a model
- generate additive diff SQL for each version step
- auto-generate `infer_when` probes for tables/columns/indexes

Run them with `Migrator::run`.

## Update Set Macro

Use `d1_sets!` to build update pairs for generated `update_by_*` methods:

```rust
let sets = d1_orm::d1_sets! {
    "name" => d1_orm::JsValue::from_str("Alice"),
    "avatar_url" => d1_orm::JsValue::NULL,
};
User::update_by_id(db, 1_i64, &sets).await?;
```

## Raw Query Macros

For complex predicates, use typed raw-query macros:

```rust
let rows = d1_orm::d1_query_all!(
    db,
    UserItem,
    "SELECT * FROM user_items_v2 WHERE user_id = ? AND status != ?",
    [d1_orm::JsValue::from_f64(1.0), d1_orm::JsValue::from_f64(0.0)]
)?;
```

- `d1_query_all!` -> `Result<Vec<T>, d1_orm::Error>`
- `d1_query_first!` -> `Result<Option<T>, d1_orm::Error>`

## Batch Macro

Use `d1_exec_batch!` to run multiple bindable statements in a single D1 batch:

```rust
let cleanup = repo.delete().where_lt("expires_at", d1_orm::JsValue::from_f64(now as f64));
let upsert = repo
    .insert()
    .set("id", id)
    .set("state_json", state_json)
    .set("expires_at", d1_orm::JsValue::from_f64(expires_at as f64))
    .on_conflict("(id) DO UPDATE SET state_json=excluded.state_json, expires_at=excluded.expires_at");

d1_orm::d1_exec_batch!(db, [cleanup, upsert])?;
```

## Notes

- SQL fragments passed into methods like `where_raw`, `join`, and `on_conflict` are not sanitized.
- This crate targets Cloudflare Worker + D1 environments.
